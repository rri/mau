Catalog

Catalog view, mock 3

Every book on your list, including finished ones. The visual style is a placeholder.

Try these

  • Switch between list and grid with the header buttons.
  • Tap Active and Inactive to turn them off, leaving Finished. Then tick Owned? and tap #classics. Filters combine.
  • Search for "ishiguro".
  • Change the sort to Author or Recently finished.

Approved decisions shown

  • List and grid layouts, switchable.
  • State chips Active, Inactive, Finished: several can be selected, and all three are on by default.
  • An Owned? checkbox on the same row as the state chips.
  • Text search, and tag chips where several tags must all match.
  • Sort menu, defaulting to recently added.
  • Adding a book is the + in the catalog header.
  • Bottom tab bar: Reading, Catalog, Settings.
  • Tapping a book opens its detail page (the next mock).
  • Rows don't separate unstarted from paused: both say Inactive, with pages if there's progress.
  • Finished books show only the latest finish date; all read dates go on the detail page.
  • The grid shows cover artwork.

Open questions for this screen

  1. Unchecking Owned? shows all books, owned or not. There's no way to see only books you don't own. Mock: as described.
  2. Turning off all three state chips. Mock: allowed; the list is empty with a hint. Alternative: the last chip can't be turned off.
  3. What a list row shows. Mock: cover, title, author, state with pages or finish date, up to two tags, and a bookshelf icon if owned.
  4. What a grid tile shows. Mock: cover artwork with badges (dot if active, check if finished, shelf if owned), a progress bar if started and unfinished, and the title below.
  5. The artwork here is drawn as a stand-in, because the mock can't load real images. Where real covers come from is a backend decision: the online catalog, your own upload, or both.
  6. A book with no cover image. Proposal: fall back to a generated tile like these.
  7. Should the list view and the progress view use real cover thumbnails too, instead of the generated initials? Mock: initials tiles there for now.
  8. Is the title under the cover needed in the grid, since the cover usually shows it? Mock: shown.
  9. Title sort ignores a leading "The", "A", or "An"? Mock: yes.
  10. Author sort uses the surname? Mock: yes. Le Guin sorts under L.
  11. How "Recently finished" treats unfinished books. Mock: they go after all finished books, by date added.
  12. Are the remembered layout, sort, and filters kept per device or per account? Mock: n/a; layout and sort would be remembered, filters reset each visit.
  13. A count line ("16 books", "3 of 16 books"). Keep it?
  14. On desktop, the tab bar becomes a left sidebar. Not shown in this phone-width mock.
