Try these

  • Tap + and watch today's square in the activity calendar darken.
  • Set a rating, then tap the same star again to clear it.
  • Type "fa" in the tag field. It suggests #fantasy and #favorites; Enter picks the highlighted one. Typing a tag that doesn't exist offers "Create new tag" exactly as typed.
  • Add and remove copies, choosing an edition. "Owned" follows from having a copy.
  • On The Dispossessed, tap Re-read to start a third reading.
  • Open the ⋯ menu for Edit details (including a cover upload) and Remove from list.

Approved decisions shown

  • One 1–5 star rating and one notes field per book. Tapping the current star clears it.
  • Copies record format and location only. No lending.
  • One activity calendar for the whole book: one row per year with reading, skipping empty years. Legend is just Less … More. Daily summaries below.
  • Each copy shows its edition.
  • The tag field autocompletes existing tags as you type. No fuzzy matching or correction: tags match verbatim.
  • Section order, autosaving notes, Edit details fields (title, author, cover), the remove confirmation, and the header line are approved as mocked.
  • The same activate, pause, +, and page-edit controls as the progress view.
  • Activating a finished book starts a re-read at page 0 with the same total.
  • Edit details is a personal override, including uploading your own cover.
  • Removing a book deletes it permanently after confirmation.
  • No cover image falls back to a generated book cover with the title and author.

Open questions for this screen

  1. Format and edition overlap: an edition is usually already a paperback, hardcover, or ebook. Should picking an edition fill in the format automatically, with format chosen by hand only for "Unknown edition"? Mock: both chosen separately.
  2. What a copy's edition line shows. Mock: publisher, binding, and year. ISBN could be added. The edition names here are made-up examples.
  3. Where the list of editions in "Add copy" comes from. Proposal: editions of this work from the online catalog, plus any added by ISBN scan or by hand. Belongs with the add-book flow.
  4. Tags are saved exactly as typed, so "Sci-Fi" and "sci-fi" are different tags. Autocomplete finds existing tags regardless of case, so you'd normally pick the existing one. As mocked.
